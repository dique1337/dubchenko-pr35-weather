# WeatherApp — Инструкция по установке

## Структура файлов
```
/weather/
├── index.php
├── login.php
├── register.php
├── forgot_password.php
├── logout.php
├── home.php
├── profile.php
├── admin.php
├── config.php
├── auth_check.php
├── logger.php
├── weather_api.php
├── database.sql
└── api/
    └── weather.php
```

## Шаги установки

### 1. База данных
- Откройте phpMyAdmin → создайте БД `weather`
- Импортируйте файл `database.sql`
- Готово! Таблицы созданы, демо-admin добавлен

### 2. Файлы
- Скопируйте все файлы в папку `C:\OpenServer\domains\weather\`
- Создайте папку `uploads/avatars/`
- Поместите `default_avatar.png` в `uploads/avatars/`

### 3. Папка API
- Создайте папку `api/` внутри проекта
- Скопируйте `api/weather.php` туда

### 4. Проверка config.php
```php
$host = 'localhost';
$db   = 'weather';
$user = 'root';
$pass = '';
```
Измените под свои настройки OpenServer если нужно.

## Функциональность

### Авторизация
- ✅ Регистрация с кодом подтверждения (код выводится на экран)
- ✅ Вход по логину или email
- ✅ Защита от brute-force (5 попыток / 15 минут)
- ✅ CSRF-токены на всех формах
- ✅ XSS защита (htmlspecialchars везде)
- ✅ Восстановление пароля (код на экране)
- ✅ Выход из системы с логированием

### Погода (OpenWeatherMap API)
- ✅ Текущая погода (температура, влажность, давление, ветер, видимость)
- ✅ Почасовой прогноз (16 шагов по 3 часа)
- ✅ Прогноз на 7 дней
- ✅ УФ-индекс (через One Call API v3)
- ✅ Качество воздуха (AQI)
- ✅ Восход/закат солнца
- ✅ Осадки (дождь/снег)
- ✅ Кеширование в БД (10 минут TTL)
- ✅ Автоматические алерты (сильный ветер, жара, мороз, УФ)
- ✅ °C / °F переключение

### Поиск и геолокация
- ✅ Автодополнение городов (от 2 символов)
- ✅ Геолокация через браузер
- ✅ Сохранение последнего города в localStorage
- ✅ Запоминание последнего города при обновлении страницы

### Избранное
- ✅ Добавление / удаление городов (макс. 10)
- ✅ Быстрое переключение между городами
- ✅ Мини-температура в списке избранного

### Графики
- ✅ График температуры и осадков (Chart.js)
- ✅ График влажности

### Администратор
- ✅ Включение/выключение параметров для пользователей
- ✅ Управление пользователями + смена ролей
- ✅ Логи безопасности (последние 100)
- ✅ Управление городами
- ✅ Очистка кеша погоды
- ✅ Статистика системы

### Профиль
- ✅ Смена имени / аватара
- ✅ Смена пароля (с подтверждением старого)
- ✅ Переключение °C / °F
- ✅ Удаление аккаунта с подтверждением

## Примечание по email
Email-отправка не настроена (OpenServer не имеет SMTP).
Коды подтверждения и восстановления выводятся прямо на экране.
Для реальной отправки добавьте PHPMailer + Gmail SMTP в config.php.
