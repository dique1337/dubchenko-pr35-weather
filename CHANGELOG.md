# CHANGELOG

## [1.0.0] - 2026-04-05
### Добавлено
- REST API: четыре endpoint (read, create, update, delete)
- Валидация всех форм на сервере
- README.md с инструкцией запуска
- **Ядро системы (PHP):** Реализована архитектура приложения на PHP 8.1.
- **Работа с данными:** Интеграция с базой данных MySQL для хранения пользователей и истории запросов.
- **REST API:** Реализованы эндпоинты для получения данных о погоде (интеграция с внешними метео-сервисами).
- **Система ролей:** 
  - `admin` — доступ к управлению и логам.
  - `user` — личный кабинет и избранные города.
  - `guest` — базовый просмотр погоды.
- **Интерфейс:** Адаптивная верстка на Bootstrap 5.
- **Документация:** Созданы файлы README.md (инструкция) и руководство пользователя.

### Исправлено
- **JSON:** Добавлена поддержка кириллицы в ответах API через флаг `JSON_UNESCAPED_UNICODE`.
- **Маршрутизация:** Исправлены ошибки путей при запуске проекта в подпапках OpenServer.
- **Сессии:** Исправлен баг с потерей авторизации при переходе между страницами.

### Безопасность
- **Валидация:** Введена строгая фильтрация всех входящих данных из форм ($_POST, $_GET).
- **Доступ:** Добавлены функции-контроллеры `requireLogin()` и `requireRole()` для защиты приватных разделов.
- **SQL-инъекции:** Использование подготовленных выражений (Prepared Statements) при работе с БД.
